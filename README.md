# 造梦西游3 完全本地离线版

4399《造梦西游3 大闹天庭篇》的本地离线运行版：不联网、不需要 4399 账号，
双击 `start.bat` 即可游玩，存档保存在本地。

## 快速开始

1. 安装 Python 3（用于本地静态服务）；
2. 准备 Flash Player 独立播放器 `flashplayer_sa.exe`，
   放到 `D:\4399\tools\flashplayer_sa.exe`（或修改 `start.ps1` 里的路径）；
3. 双击 `start.bat`。

启动后：

- 本地服务：`http://127.0.0.1:8765`
- 游戏窗口：Flash Player 独立播放器
- 存档：`%APPDATA%\Macromedia\Flash Player\#SharedObjects\...\127.0.0.1\launcher.swf\zmxy3_offline.sol`

## 画质与帧率

- **帧率**：游戏引擎固定 24 帧，所有逻辑（移动、技能、刷怪）都按帧计时。
  强行提高 `stage.frameRate` 会让整个游戏加速，所以正确做法是保持 24 帧稳定。
  实测 1x / 1.5x / 2x 窗口下都是 24.0 FPS。
- **清晰度**：默认以 1.5 倍分辨率渲染（940×590 → 1410×885），并给
  Flash Player 打开 `HIGHDPIAWARE`，避免 Windows 150% 缩放导致的整体模糊。
- **启动参数**：

```bat
start.bat                 :: 默认 1.5x
start.bat 1               :: 原始 1x（最小最锐）
start.bat 2               :: 2x（大屏）
start.bat 1.5 -Fps        :: 右上角显示帧率
start.bat 1.5 -Sharp      :: 关闭位图平滑，像素更硬
start.bat 1.5 -Pillar     :: 全屏时保持比例（两侧留黑边），默认是拉伸铺满
```

全屏/宽比例窗口默认用 `EXACT_FIT` 拉伸铺满，不会再出现右侧单边黑边；
如果你更在意比例不变形，加 `-Pillar` 就回到等比 + 居中黑边。

## 地图工具箱（自选道具 / DIY 属性）

进入世界地图后，右下角会出现 **「工具箱」** 按钮：

- 左侧 381 项道具，可按 `全部 / 武器 / 防具 / 饰品 / 其他` 分类，支持搜索；
- 选中道具后右侧显示它的模板属性；
- 可自定义：攻击、防御、生命、魔法、暴击、闪避、回血、回蓝、吸血、魔抗、穿透、数量；
- 点「加入背包」会生成一个**独立副本**（不改模板），自动放进背包并**立即存档**。

小提示：地图界面点「背包」即可看到刚添加的道具，穿上后属性立刻生效。

## 原理

游戏逻辑与 4399 平台通过 `GMain.setHold(hold)` 解耦。离线版：

1. 把 `save.api.4399.com` 的取时间接口等长替换为本地 `/time`；
2. 把 `Config.checkWebUid()` 改成恒返回 `true`；
3. 注入 `LocalHold`：假账号 + `SharedObject` 存档，充值/排行/公会空实现。
